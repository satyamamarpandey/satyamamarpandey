## What I Build

I build systems that move beyond analysis and recommendations into real workflows.

My current work spans:

- Investment research and valuation systems
- Voice AI and real-time conversational infrastructure
- Business creation and publishing automation
- Career workflow automation
- Website growth intelligence
- Systematic trading research
- Automated media production
- Mobile and web applications
- Data science, machine learning and quantitative analytics

A recurring idea across much of my work is:
